🎮 Quick Guide

  • File Manager — upload EPUB/TTF files, create folders, delete or preview what is on the SD card.
  • Settings — reader preferences, Wi-Fi, the OpenClaw gateway and the MiMo speech key; every panel carries its own usage hint, plus Save / Reset Defaults / Reboot buttons.
  • Fonts — install a CJK font family from a folder on the SD card so book titles render in Chinese.
  • The 中文 / EN button in the top right switches this whole interface language.
