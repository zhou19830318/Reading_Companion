### 在网络中看不到设备

**问题：** 浏览器显示“无法连接”或“无法访问此网站”

**解决方案：**

1. 确认两台设备都在正确的网络上
   - 检查你的电脑/手机的 Wi-Fi 设置
   - 在 **加入网络** 模式下，你的电脑/手机和 CrossPoint 阅读器必须在同一个 Wi-Fi 网络上
   - 在 **创建热点** 模式下，你的电脑/手机必须已连接到 `CrossPoint-Reader` 热点
2. 仔细检查 IP 地址
   - 确保输入正确
   - 开头要包含 `http://`
   - 在 OnePage 上，请始终使用屏幕上打印的 IP 地址——mDNS 未编译进 C61 构建，因此 `http://crosspoint.local/` 永远无法解析
3. 如果你正在使用 VPN，尝试将其禁用
4. 某些网络启用了“客户端隔离”——请使用创建热点模式，或与你的网络管理员确认

### 连接中断或超时

**问题：** Wi-Fi 连接不稳定

**解决方案：**

1. 靠近 Wi-Fi 路由器，或使用创建热点模式进行直连
2. 检查设备上的信号强度（应至少为 `||` 或更好）
3. 避免其他设备的干扰
4. 如果可用，尝试其他的 Wi-Fi 网络

### 上传失败

**问题：** 文件上传无法完成或显示错误

**解决方案：**

1. 检查 SD 卡是否有足够的可用空间
2. 检查文件名对 SD 卡文件系统是否有效
3. 先尝试上传较小的文件进行测试
4. 刷新浏览器页面并重试
5. 如果 WebSocket 上传反复失败，请刷新页面并通过 HTTP 后备路径重试

### 已保存的密码不起作用

**问题：** 设备使用已保存的凭据无法连接

**解决方案：**

1. 连接失败时，系统会提示你“忘记网络”
2. 选择 **是** 以移除已保存的密码
3. 重新连接并再次输入密码
4. 选择保存新密码

## OnePage 专有问题

### 保存后设置页面显示过时的值

**问题：** 保存的更改（或恢复出厂设置）在设置页面重新加载后没有显示生效。

**解决方案：**

1. 强制刷新页面（Ctrl/Cmd+Shift+R）——`GET /api/settings` 没有缓存头，因此浏览器可能重放旧响应
2. 针对 API 编写脚本时，附加一个缓存穿透参数：
   `/api/settings?lang=en&_=<timestamp>`

### 语音助手无响应

**问题：** **AI 助手** 或其它语音功能无法连接到中继。

**解决方案：**

1. 在 Web 界面打开 **设置 → 云服务**，核对 Relay URL（`ws://` 或 `wss://`）、Device ID 与 Token；Token 只显示“已保存/未保存”，不会回显
2. 确认 **设置 → 系统 → Voice Relay** 总开关处于开启状态
3. 设备侧没有直连云端或本地兜底：中继不可达时界面会显示具体原因（未配置 / 无网络 / 服务繁忙 / 配额耗尽 / 设备被拒）。对着这些提示先排查中继服务（`systemctl status reading-companion-relay`、`/readyz`），而不是设备
4. 阅读器必须联网（**文件传输 → 加入网络** 或正常 Wi-Fi 连接）才能访问中继
5. 设备时间未同步时，聊天历史不会落盘——先让设备联网走一次 SNTP

### 不应使用固件更新

**问题：** **设置 → 系统 → 检查更新** 提供了下载。

该条目仍在轮询上游 CrossPoint 版本发布，其发布的是 ESP32-C3 镜像。它与 OnePage（ESP32-C61）不兼容——请忽略它，改为通过 USB 刷写；参见 [README](../README.md#安装固件)。
